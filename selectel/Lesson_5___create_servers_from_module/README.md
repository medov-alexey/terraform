# Урок 5 — Развертывание пула серверов в облаке Selectel через модули

Из-под существующего сервисного пользователя в целевом проекте автоматически разворачивается 6 изолированных виртуальных машин (доступ по SSH под пользователем `root`).

Глобальная сеть и общие ресурсы создаются в корневом проекте, а сами серверы генерируются циклически с помощью повторно используемого шаблона (модуля) и конфигурационного файла `vps_list.tf`.

## 🛠 Структура проекта

* `auth.tf` — конфигурация и авторизация провайдеров Selectel и OpenStack.
* `variables.tf` — объявление входных переменных (без хранения секретов).
* `vps_list.tf` — изолированный декларативный список серверов для развертывания.
* `main.tf` — глобальная сетевая обвязка (LAN, роутер, SSH-ключ, общий Flavor) и вызов модуля.
* `modules/vps/` — изолированный шаблон (модуль) для сборки единицы сервера (диск + порт + инстанс + Floating IP).

## 🚀 Пошаговое руководство по запуску

### Шаг 1. Активация учетных данных и секретов
Так как секреты не хранятся в коде (вклад в безопасность), перед запуском Terraform необходимо наполнить переменные окружения вашей текущей терминальной сессии.

Выполните команду для импорта настроек из вашего файла конфигурации:
```bash
source ~/terraform-selectel
```

### Шаг 2. Инициализация проекта
Загрузка необходимых провайдеров (`selectel` и `openstack`) для корневого контекста и для дочернего модуля `vps`:
```bash
terraform init
```
*Если вы ранее меняли структуру провайдеров или версий, используйте команду очистки кэша: `terraform init -reconfigure`*

### Шаг 3. Предварительный просмотр плана
Сверка текущего состояния облака с кодом. Terraform должен показать план на добавление **41 ресурса** (сеть + роутер + ключ + 1 общий флейвор + по 6 дисков/портов/серверов/IP/линков):
```bash
terraform plan
```

### Шаг 4. Применение конфигурации (Создание инфраструктуры)
Запуск процесса создания сети и всех 6 серверов в облаке. По окончании процесса в консоль выведется список всех выделенных публичных IP-адресов:
```bash
terraform apply
```

### Шаг 5. Подключение к серверам
После успешного завершения `apply` возьмите публичный IP-адрес нужного сервера из блока `Outputs` в консоли и подключитесь по SSH:
```bash
ssh root@<полученный_публичный_ip>
```

## 🔄 Масштабирование инфраструктуры (Добавление / Удаление серверов)

Вся прелесть текущей архитектуры в том, что вам **не нужно править файлы `main.tf` или `auth.tf`**. 

1. Откройте файл `vps_list.tf`.
2. Измените список серверов в блоке `default`:
   * **Чтобы добавить сервер:** Просто допишите новую строку с уникальным именем (например, `"monitoring-node"`).
   * **Чтобы удалить конкретный сервер:** Удалите или закомментируйте строку с его именем (например, `#"cache-server"`).
3. Запустите `terraform plan`, чтобы убедиться, что Terraform затронет **только измененный сервер**, а остальные продолжат работать без перезагрузки.
4. Выполните `terraform apply`.

---

## 🗑 Полное уничтожение лабораторной работы
Когда учебные серверы больше не нужны, полностью удалите всю созданную инфраструктуру и освободите публичные IP-адреса в Selectel, чтобы за них не списывались деньги:
```bash
terraform destroy
```
